# look

`look.bundle.js` beside this file is the single-file build of
`rails49/look@v0.6.0`, committed because the box may have no internet. The page loads it from `/look/`, and it
draws the page's band.

A release of look opens a pull request here that replaces the file and moves
every `rails49/look@v…` and `rails49/look#v…` to the new tag, this line and the
gate's `look-check` among them. It merges itself when the gate is green.
